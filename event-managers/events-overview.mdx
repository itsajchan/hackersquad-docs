The Events Overview page gives you a complete picture of your company's event activity on HackerSquad — both events you are running and events you are sponsoring.

## Event stats

At the top of the page, four key metrics summarize your event activity:

| Metric | Description |
| --- | --- |
| **Events Running** | Total number of events your company has created |
| **Upcoming (Running)** | Events you created that are scheduled in the future |
| **Events Sponsoring** | Total number of events your company is sponsoring |
| **Upcoming (Sponsoring)** | Sponsored events that are scheduled in the future |

## Events you're running

This section lists all events created by your company. Each event card displays:

- Event name and date
- Event format badge (e.g., Hack Night, Hackathon, Demo Day)
- Location
- Status indicator (upcoming or past)

**Upcoming events** appear first, followed by **past events**. Click on any event to open the full [Event Management dashboard](/event-management/overview) where you can manage registrations, projects, judging, and more.

<Tip>Use the event format badge to quickly identify the type of each event at a glance.</Tip>

## Events you're sponsoring

This section shows all events where your company holds a sponsorship. Each entry displays the event name, date, your sponsorship tier, and the event organizer.

Click on a sponsored event to view the event details page, including your sponsorship benefits and any deliverables.

To browse and sponsor new events, visit the [Event Marketplace](/company-portal/event-marketplace).
