Projects are built by teams or individuals. They represent a teams effort and grind to solve a problem based on your problem statement. In the **event manager portal**, you can view all projects, their descriptions, the tools they've selected to use in that project, their project video, a GitHub link to their code and more.

<Note>You can view projects on the free plan.</Note>

There are two ways to navigate to view projects.

## Project List

The projects are laid out in a vertical list of expandable projects. There are icons for company logos that indicate what each tool was used in that particular project. The selectable list of companies are the [added partner companies](/event-managers/add-partner-companies) in that event. 

![Project list](/images/project-list.png)

## Expanded Project View

<Steps>
  <Step title="Open the event creation form">
    Navigate to your [Events Overview](/company-portal/events-overview) page and click the **Create Event** button. You can also start from the dashboard by clicking the **Run Events** card.
  </Step>
  <Step title="Enter event details">
    Fill in the following fields:

    - **Event Name** — A clear, descriptive title for your event
    - **Description** — A detailed overview of what attendees can expect, including goals, agenda, and any requirements
    - **Event Format** — Select from the formats listed above
    - **Start Date & Time** — When the event begins
    - **End Date & Time** — When the event ends
    - **Location / Address** — The physical venue or indicate if the event is virtual
    - **Event Image** — Upload a cover image for the event listing
    - **Registration Link** — Paste the URL where attendees can register (e.g., a Luma event link)
  </Step>
  <Step title="Review and publish">
    Review your event details and click **Create Event** to publish. Your event will appear on the [Events Overview](/company-portal/events-overview) page and can be managed through the [Event Management dashboard](/event-management/overview).
  </Step>
</Steps>

<Tip>Set up a Luma event first for registration, then paste the registration link into the HackerSquad event form.</Tip>

## After creating your event

Once your event is live, you can:

- **Manage registrations** — Track who has signed up and their roles. See [Registrations](/event-management/registrations).
- **Configure settings** — Set up judging, Cloud IDE, password protection, and more. See [Event Settings](/event-management/event-settings).
- **Invite speakers** — Add speakers to your event lineup. See [Speakers](/event-management/speakers).
- **Set up prizes** — Create prize categories and configure sponsorship tiers. See [Prizes](/event-management/prizes).
