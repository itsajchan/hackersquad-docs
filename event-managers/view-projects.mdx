Projects are built by teams or individuals. They represent a teams effort and grind to solve a problem based on your problem statement. In the **event manager portal**, you can view all projects, their descriptions, the tools they've selected to use in that project, their project video, a GitHub link to their code and more.

<Note>You can view projects on the free plan.</Note>

There are two ways to navigate to view projects.

## Project List

The projects are laid out in a vertical list of expandable projects. There are icons for company logos that indicate what each tool was used in that particular project. The selectable list of companies are the [added partner companies](/event-managers/manage-partner-companies) in that event. 

![Project list](/images/project-list.png)

| Element | What it shows |
| --- | --- |
| **Filter by company** | Use this dropdown to narrow the list to projects that used a specific partner company. |
| **Project count** | This shows how many projects match the current filter. |
| **Expand all / Collapse all** | Use these controls to open or close every project in the list at once. |
| **Project row** | Each row shows a project's name, ranking number, and builder information. |
| **Tool logos** | These icons show which partner tools were used in the submission. |
| **Votes** | This shows the current vote count for the project. |
| **Expand arrow** | Click this to open the full project details for a single submission. |

## Expanded Project View

![Expanded project view](/images/expanded-project-view.png)

| Box | What it shows |
| --- | --- |
| **1** | The project header. This area shows the project name and the tool logos associated with that submission. |
| **2** | The project description. Use this section to understand what the team built and what problem they are solving. |
| **3** | The technologies used field. This shows the tools and platforms the team selected for the project. |
| **4** | The demo approval status. This control shows whether the project demo has been approved yet. Approved projects get a presentation button to demo live.|
