![Builder terminal in HackerSquad](/images/builder-terminal.png)

To host an event, you'll need to have Manager access to an event. These docs guide you to view project details as an event manager, add partnering companies to the event, add other event managers, update a photo gallery, and more.

![Manager button in HackerSquad](/images/event-manager-button.png)

If you are event manager for an event, you will see this `Manage` button on a given event. 

<Tip>If you should be an event manager but you aren't, reach out to the event host to add your email .</Tip>

Once you're an event manager, you'll have access to all the features that help you manage a hackathon successfully.
