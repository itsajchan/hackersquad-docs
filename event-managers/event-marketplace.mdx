The Event Marketplace is where companies discover developer events happening across the HackerSquad network. Browse upcoming events, review event details, and secure sponsorship slots that put your tools in front of engaged builders.

<Note>You must have a company profile set up before you can sponsor events. See [Company Setup](/company-setup) to get started.</Note>

## Browsing events

The marketplace displays all upcoming public events on HackerSquad. Each event listing shows:

- **Event name** and cover image
- **Date and time** (start and end)
- **Location** (venue address or virtual)
- **Event format** (Hack Night, Hackathon, Demo Day, etc.)
- **Organizer** information
- **Sponsorship availability** — whether sponsorship tiers are still open

Use the marketplace to find events that align with your target audience, technology stack, or geographic focus.

## Viewing event details

Click on any event to open its detail page. The event detail view includes:

- Full event description and agenda
- Event format and expected attendance
- Organizer and any confirmed sponsors
- Available sponsorship tiers with pricing and benefits
- Registration link for attendees

<Tip>Look for events in your target developer community. Hack Nights and Hackathons attract builders who actively code with new tools — ideal for hands-on product exposure.</Tip>

## Sponsorship tiers

Events on HackerSquad use a tiered sponsorship model. Event organizers configure which tiers are available and what each tier includes. The standard tiers are:

| Tier | Description |
| --- | --- |
| **Diamond** | Top-tier sponsorship with maximum visibility, dedicated speaking slot, and prime booth placement |
| **Platinum** | Premium sponsorship with logo placement, demo time, and prominent branding |
| **Gold** | Mid-tier sponsorship with logo on event materials, prize contribution, and attendee access |
| **Silver** | Standard sponsorship with logo visibility, social mentions, and swag table |
| **Bronze** | Entry-level sponsorship with logo placement and community recognition |

Benefits vary by event. Review the specific tier details on each event's sponsorship page before purchasing.

## Checking availability

Each event listing indicates how many sponsorship slots remain per tier. Tiers with no remaining slots are marked as **Sold Out**. Popular events fill quickly, so secure your preferred tier early.
