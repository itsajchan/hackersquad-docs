The HackerSquad events directory at [hackersquad.io/events](https://hackersquad.io/events) is where you discover upcoming developer events in your area and beyond.

## Browsing events

The events page displays all public events with key details at a glance:

- **Event name** and cover image
- **Date and time** (start and end)
- **Location** or virtual indicator
- **Event format** badge (e.g., Hackathon, Hack Night, Workshop)
- **Registration status** — whether the event is open for signups

## Event formats

HackerSquad supports a variety of event formats. Each format is designed for a different type of experience:

| Format | Description |
| --- | --- |
| **Hack Night** | An evening coding session, typically 4-6 hours |
| **Hack Day** | A full-day building event |
| **Hackathon** | A multi-day event with project submissions and judging |
| **Demo Day** | Focused on presenting finished projects to an audience |
| **Workshop** | Hands-on learning sessions led by instructors or speakers |
| **Mini Conference** | Short talks and panels with networking |
| **Meetup** | Casual community gathering for developers |
| **Panel Discussion** | Moderated discussions with industry speakers |
| **Builder Battlegrounds** | Competitive head-to-head building challenges |
| **Yoga Workshop** | Wellness sessions for the developer community |

<Tip>Look at the event format to set your expectations. A **Hack Night** is a quick evening sprint, while a **Hackathon** is a multi-day commitment with judging and prizes.</Tip>

## Viewing event details

Click on any event to see the full details page, which includes:

- **Description** — What the event is about, goals, and themes
- **Schedule** — Start and end times
- **Location** — Venue address or virtual event link
- **Sponsors** — Companies sponsoring the event and their technologies
- **Registration link** — Button to register for the event
- **Projects** — Previously submitted projects (if the event has started)
- **Leaderboard** — Rankings and scores (if judging is active)

## Filtering and search

Use the events directory to find events that match your interests:

- **By format** — Filter by event type (Hackathon, Workshop, Meetup, etc.)
- **By date** — Browse upcoming events sorted chronologically
- **By location** — Find events near you
