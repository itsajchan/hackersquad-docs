## Plan details

### Free — $0/mo

The Free plan is ideal for getting started with HackerSquad. You can create up to **3 events per month**, manage registrations, and access core event features like project submissions, judging, and leaderboards.

### Starter — $1,000/mo

The Starter plan raises your event limit to **10 events per month** and is suited for growing teams that run events regularly. All core features are included.

### Pro — $2,000/mo

The Pro plan unlocks premium capabilities for teams that need more from the platform:

- **15 events per month**
- **1,000 Cloud IDE hours** — give builders a browser-based coding environment at your events
- **Streaming and recording** — live demo and speaker streaming via WebRTC with automatic recording
- **Advanced analytics** — deeper insights into event performance and attendee engagement
- **Social Content Generator** — AI-powered social post creation from your content library

### Scale — $3,500/mo

The Scale plan is built for organizations managing high-volume developer programs:

- **25 events per month**
- **2,000 Cloud IDE hours**
- All Pro features, plus:
- **White-label branding** — customize the event experience with your own branding

### Enterprise — Custom pricing

The Enterprise plan removes all limits and adds dedicated support:

- **Unlimited events**
- **Unlimited Cloud IDE hours**
- All Scale features, plus:
- **Dedicated account manager**
- **API access** for programmatic integrations

Contact [inquiry@hackersquad.io](mailto:inquiry@hackersquad.io) to discuss Enterprise pricing.

## Feature gating

Certain features are only available on specific plans:

| Feature | Required plan |
| --- | --- |
| Social Content Generator | Pro or higher |
| Cloud IDE | Pro or higher |
| White-label branding | Scale or higher |
| API access | Enterprise |

<Warning>
Events created beyond your monthly limit will be blocked. Upgrade your plan to increase your event capacity.
</Warning>

## How to upgrade

You can view all plans and upgrade directly from the platform. Visit the [pricing page](https://hackersquad.io/#pricing) to compare plans and choose the tier that fits your needs.

<Tip>
Start with the Free plan to explore the platform, then upgrade as your event program grows.
</Tip>
